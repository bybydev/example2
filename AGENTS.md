# AGENTS.md

## Rules

- Do not run install, build, test, or render commands locally (e.g. `npm install`, `npm run build`, `npm test`, `tsc`, `remotion render`). The user compiles, tests, and renders in GitHub Actions; after edits, report what changed.
- Do not edit `src/generated/timeline.json` by hand — it is generated by `mycli remotion timeline` from `video.config.json`, `content/voiceover.md`, `public/voiceover/*.mp3`, and `content/timings/*.json`.
- Follow `WORKFLOW.md` step by step and check off completed pass conditions (`- [x]`) as each step finishes.
- Always start a new Short by drafting and iterating on `content/storyboard.md` first; wait for explicit user approval before moving on to writing `content/voiceover.md`.
- Always ask the user for explicit permission before running `mycli remotion sync` (voice is pre-configured in `~/.mycli/.env`, so no `--voice` flag is needed).

## Creative Direction Rules (IMPORTANT)

- **This is a template, NOT a fixed visual mold — do not follow the demo design blindly.** Starter chapters (`src/chapters/01-hook`, `src/chapters/02-main-point`), `src/Thumbnail.tsx`, and shared UI primitives are optional building blocks and a minimal reference demo. Every Short should have its own bespoke visual style, custom SVGs/diagrams/illustrations, layout rhythm, and storytelling structure tailored to its topic and approved `content/storyboard.md`.
- **Stop stamping titles, eyebrows, and headers on every frame.** `Stage` defaults to `showHeader={false}`. Do **not** repeat an eyebrow + title + subtitle banner (`SectionTitle`) at the top of every scene — let pure visuals, diagrams, kinetic numbers, or focused metaphors carry the frame. Use headlines only when text itself is the focal beat.
- **Focus purely on video content.** Do not add channel watermarks or branding badges onto the canvas; channel consistency comes from sharing the core color palette, typography, and motion craft.
- **Hook immediately on frame 0.** Never fade in from black on frame 0 — the opening frame must be immediately bold and legible for both the Shorts feed and YouTube's Shorts frame picker.

## Project Architecture

- **Canvas & Shorts safe zones (`1080×1920`, `9:16`, `30 fps`):** Respect YouTube Shorts mobile UI overlays via `TOKENS.layout` (`safeTop: 220`, `safeBottom: 440`, `safeLeft: 72`, `safeRight: 148`, `captionReserve: 200`). Prefer 1-column vertical stacks or at most 2-column grids; keep `CodePanel` lines concise (≤ 36 chars). Use `showSafeZoneGuide` in `VideoProps` (Remotion Studio) when auditing placement.
- **Script & narration:** `content/voiceover.md` has one paragraph per blank line; each paragraph maps 1:1 to a voiceover clip in `public/voiceover/` and a Whisper word-timing sidecar in `content/timings/`. Keep Shorts tight (target **30–60s** / ~75–150 words; hard YouTube Shorts cap **180s**) with short 1–2 sentence paragraphs for rapid visual pacing.
- **Visual plan:** Read `content/storyboard.md` before implementing or updating scenes.
- **Chapter isolation:** Each chapter/beat lives in its own folder under `src/chapters/<id>/index.tsx` and is registered in `src/chapters/index.ts` and `video.config.json`. Keep edits scoped to the target chapter whenever possible.
- **Timing-driven animation:** Anchor visual transitions to spoken words instead of hardcoded frame numbers. Use `src/lib/timeline.ts` (`chapterById`, `chapterClips`, `wordFrame`) and helpers in `src/ui/motion.ts` (`clipRange`, `cueFrame`, `sceneWindow`, `fadeIn`, `progressBetween`, `springAt`, `slideUpStyle`, `popScaleStyle`).
- **Design toolkit:** Reuse or adapt semantic tokens in `src/theme/tokens.ts` (`TOKENS`, `SemanticTone`, `TONE_STYLES`), bundled fonts in `public/fonts/` (`src/theme/fonts.ts`, `TOKENS.fonts.sans/mono/display/handwritten`), optional UI primitives in `src/ui/primitives.tsx` (`SceneBeat`, `Card`, `Pill`, `SectionTitle`, `DataChip`, `MeterBar`, `AnimatedNumber`, `StatCallout`, `RelatedVideoCTA`), and diagram helpers in `src/ui/diagrams.tsx` (`NodeBox`, `CodePanel`, `CheckRow`, `SvgLink`, `SvgPacket`, `VerticalFlowConnector`). Build custom SVG/motion components freely whenever the topic calls for them.
- **Burned-in captions & SRT:** `CaptionsOverlay` (`src/lib/captions.tsx`) is **enabled by default** (`showCaptions: true` in `src/Root.tsx` and `src/Video.tsx`), rendering 2–4 word kinetic highlight chunks in the lower-middle caption band. Also keep `content/subtitles.srt` generated via `mycli` for YouTube CC/accessibility.
- **Audio, SFX & music:** Bundled SFX live in `public/sfx/` (see `public/sfx/README.md`) and background music lives in `public/music/bg-ambient.mp3` (see `public/music/README.md`). Trigger SFX with `<Sfx name="pop-in" from={cueFrame(...)} />` and control the music bed via `<BackgroundMusic />` from `src/lib/audio.tsx`.
- **Vertical Cover (`Thumbnail`):** `src/Thumbnail.tsx` is registered as `<Still id="Thumbnail" />` (`1080×1920`) in `src/Root.tsx` and rendered in CI to `out/thumbnail.png`. Keep focal visuals centered for both `9:16` Shorts shelves and square/`3:4` feed crops.
- **Publishing deliverables:** Keep `content/youtube-metadata.md` updated for mobile-friendly title (≤ 60 chars), Related Video link, description, hashtags/tags, and checklist.
- **Media assets:** Place chapter images/SVGs under `public/assets/<chapter-id>/` and load them via Remotion's `staticFile()`.
